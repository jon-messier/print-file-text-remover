What gets removed
  • Removed automatically: the player name and the back and front numbers, whatever they say (NAME, PLAYER, a real last name, 00, 26…), in block, sans, serif or script lettering, plus their outlines. They're found by reading the lettering, by where it sits (the name is the word next to the back number), and by the front/back number pair.
  • Kept by default: any other lettering (team names, logo text, wording that appears more than once on the garment). It's listed for each design so you can switch it on.
  • Removed paths are deleted outright. Clip groups, artwork and everything else stay exactly as they were.
  • Sizes of the same design (e.g. SM_109433.1_YS, .2_YM, … or reversible SM_111042_1_inner, _2_inner, …) share one set of choices. If one size can't be read, its lettering is matched to the other sizes.

The whole process

The vendor's print files come with the player name and numbers drawn as flattened shapes. This tool deletes those shapes and puts live NAME and 00 text in their place, so production can swap in the real names and numbers.

  1. This site: load the PDFs, check what will be removed, choose fonts and placement, download a zip.
  2. Illustrator: LiveTextBatch.jsx builds the live text in every file and saves each one as .ai.
  3. Illustrator: SwitchOpenDocsToCMYK.jsx switches the open .ai files to CMYK and saves them.

Both scripts come inside the zip you download, so there's nothing to install. The site works entirely on your computer; nothing is uploaded.

Before you start

  • Use Chrome. Fonts and the live text preview rely on it.
  • Install the fonts for the name and numbers on your Mac. Illustrator needs them to build the text.
  • Keep the vendor's file names. Sizes of one design are matched by name: SM_109433.1_YS, SM_109433.2_YM… or reversible jerseys SM_111042_1_inner, SM_111042_2_inner…
  • Put the SKU in the file or folder name (e.g. a folder called SLBB119A). It picks the standard text placement for that garment.
  • Check the version. The build stamp is under the title at the top. If it's older than expected, reload the page.

1. Load the print files

  1. Click Choose folder and pick the folder of PDFs, or drag the folder onto the page. A .zip or loose PDFs work too (Choose files or zip).
  2. Wait for the progress bar. Each file is read and its lettering identified, usually in well under a minute for a batch of 30.

Sub-folders are kept exactly as they are in the download. Anything that isn't a PDF is copied into the zip unchanged.

2. Review what's removed

The row of boxes at the top sums up the batch: files, designs, items removed, how many files need a look, and any problems.

Moving between files

  • Pick a file from the dropdown, or use ‹ › (or the ← → keys).
  • Next flagged jumps to the next file that needs attention. The flags for the current file are listed under the picture.

The picture

  • Compare: drag the slider; the original is on the left, the cleaned file on the right.
  • Original / Cleaned: show one or the other.
  • Mark removed: dashed red boxes around everything being removed.
  • Live text preview: draws the NAME / 00 that will be built (see step 3).

The Remove tab

The panel on the right is for the whole design (every size of that order). The size chips show which sizes are in it.

  • Personalization (removed): Player name, Back number, Front number. These are on by default, whatever the vendor wrote (NAME, a real name, 00, 26…). The reading and the reason are shown next to each.
  • Other lettering (kept by default): team names and logo text. Switch one on to remove it too.
  • Possible text, low confidence: shapes that might be letters. Usually artwork; leave them off unless the picture shows otherwise.

Every switch applies to all sizes of the design. Removed shapes, and their outlines, are deleted outright; clip groups and all other artwork stay exactly as they were.

3. Set up the live text

Open the Live text tab in the right panel. Settings apply to every size of the design.

SKU

Shows the SKU and size found from the file or folder name (and artboard). If it says not detected or no preset, the script has no standard placement for it; use Where vendor's text was instead.

Fonts

  1. Click Use fonts from this computer. Chrome asks permission once.
  2. Pick the font for the name and the number. Fonts are remembered for next time.

Make

Tick Back name, Back number and Front number for the lines you want. Unticking one only skips that line; everything else stays in exactly the same position.

Colors

  • Match vendor file (default): fill, stroke and stroke weight are copied from the vendor's lettering in each file, and the dropdowns show what was detected.
  • Use mine: your own choices for every size. Changing any detected color switches to this automatically, keeping the rest of what was detected.

Spot colors go by name. If a file has its own version of a swatch (e.g. the vendor's KellyGreen), Illustrator uses that file's swatch, and the preview shows it the same way.

Back placement

  • Script default: the measured standard position for the SKU and size.
  • Where vendor's text was: lines the text up with the vendor's name and number, in the vendor's order.
  • Sizes & stacking: name height, number height, gap, and whether the name sits above or below the number. Leave them blank for the SKU standard.

Front number

Placed exactly where the vendor's front number was. Same font, colors and stroke as the back number is on by default. Set the Height and the Alignment (right, center or left edge stays put).

Many designs at once

Use these fonts & placement for every design copies fonts, the Make ticks, placement and alignment to all designs. Each design keeps its own colors and stroke weights.

4. Download the zip

  1. When every flagged file has been checked, click Download cleaned zip.
  2. Unzip it. Inside you'll find:
    • the cleaned PDFs, in the same folders as you loaded them;
    • _live_text_manifest.json: the live text plan the script reads (don't edit or move it);
    • LiveTextBatch.jsx and SwitchOpenDocsToCMYK.jsx.

Keep the unzipped folder together. The script finds every PDF from the manifest at the top of it.

5. Build the live text (LiveTextBatch.jsx)

  1. Open Illustrator.
  2. Choose File › Scripts › Other Script… and pick LiveTextBatch.jsx from the unzipped folder.
  3. When asked, choose the unzipped folder (the one with _live_text_manifest.json in it).
  4. Choose the options and click Start:
    • Skip files that already have an .ai (on): safe to re-run after fixing a few files.
    • Delete each PDF after its .ai is saved (off): leave off unless you're sure.
  5. Wait. Each PDF opens, gets its NAME / 00 text (one text object per line with the Fill › Stroke › Fill appearance), is saved as .ai next to the PDF and closes.
  6. Read the summary at the end. Details for every file are in LiveTextBatch_log.txt in the folder.

The files are still in RGB at this point. That's expected; step 6 fixes it.

6. Switch to CMYK (SwitchOpenDocsToCMYK.jsx)

Illustrator only lets a script change color mode on documents that a person opened, so this is a separate step.

  1. Choose File › Open, select all the new .ai files and click Open.
  2. Choose File › Scripts › Other Script… and pick SwitchOpenDocsToCMYK.jsx. Confirm.
  3. Each RGB file is switched to CMYK, saved and closed. Files already in CMYK are closed unchanged. The default swatches Illustrator adds during the switch are removed again.
  4. Anything that didn't switch stays open and is listed at the end.

7. Final check

Open a few finished .ai files (one per design is a good habit) and check:

  • Document Color Mode is CMYK (File › Document Color Mode).
  • No leftover vendor lettering or outlines around the new text.
  • NAME and 00 are live text with Fill › Stroke › Fill in the Appearance panel.
  • Colors use the file's swatches (no duplicate swatches with the same name).
  • Team names and logos are untouched.

Flags and warnings

Found by position only (reads "…")
A number was picked from its layout (front/back pair next to a name) but didn't read clearly. Look at the picture; switch it off on the Remove tab if it's wrong.
Doesn't match the other sizes
One size found different lettering from the rest of its design. Compare it with another size.
No … found here, but other sizes of this design have one
Check that size; the lettering may be drawn differently.
Pixel check failed
Something outside the removed lettering changed. Don't use that file without a close look.
Couldn't process this file
The PDF couldn't be read. It's copied to the zip unchanged; handle it by hand.
No measured placement / no preset
The SKU or size has no standard position. Use Where vendor's text was, or ask for the SKU to be measured.
Pick a font / pick a fill color
Live text can't be built until it's set on the Live text tab.
Vendor's … isn't a production swatch
The vendor used a plain RGB or CMYK color, so your color from the Live text tab is used instead.

Troubleshooting

The site seems to be an old version
Check the build stamp under the title. Reload the page (⌘R, or ⌘⇧R to be sure).
The name or a number wasn't removed
Look in Other lettering or low confidence on the Remove tab and switch it on. If that's needed often for a design style, send the PDFs in so detection can be improved.
Something that should stay was removed
Switch it off on the Remove tab. Changes apply to all sizes of the design.
Sizes of one order show up as separate designs
The file names don't follow the vendor pattern. Rename them to match (ORDER.1_SIZE, ORDER.2_SIZE…) and load again.
"Font … is not installed on this computer"
Install the font on the Mac running Illustrator, then run LiveTextBatch again with Skip files that already have an .ai on.
The script says no manifest was found
Choose the top of the unzipped folder, where _live_text_manifest.json is.
Files are still RGB
Run step 6 on files you opened yourself with File › Open. It doesn't work on files a script opened.
Preview colors look slightly different from Illustrator
The preview is an on-screen approximation. The real color always comes from the swatch in the file.
Text sits in the wrong place
Check the SKU shown on the Live text tab. Try Where vendor's text was, or adjust Sizes & stacking.

Terms

Design
All the sizes of one order (e.g. every SM_109433.N_SIZE file). Remove switches and Live text settings apply to a whole design.
Size
One print file within a design (YS, YM, … or 1, 2, … for reversible jerseys).
Personalization
The player name, back number and front number.
Live text
Editable Illustrator text (NAME / 00) that replaces the vendor's flattened lettering.
Manifest
_live_text_manifest.json, the plan the site writes and LiveTextBatch reads.
Flag
A note that a file needs a look. Files without flags matched every check.
